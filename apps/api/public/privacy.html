1. 我们收集的信息

为提供账户、套餐与客户端授权，我们可能处理下列信息：

  • 账户信息：邮箱、昵称、密码（加密存储）、登录时间；
  • 交易信息：套餐、订单金额与状态、发票抬头与税号；
  • 用量信息：模型调用时间、所用模型标识、已使用百分比；不向你展示具体 Token 数量；
  • 客户端授权信息：用于把官网登录态授权给本机应用的一次性授权码与设备请求标识；
  • 日志与安全信息：访问时间、大致网络环境，用于排障与防滥用。

本机工作空间中的文件默认不上传到我们的服务器。只有当你发起的任务需要模型阅读这些内容时，相关片段才会发往模型供应商。

上游模型供应商的 API Key 只保存在我们的服务端，不会写入桌面客户端，也不会要求你在客户端中填写。

2. 使用目的

我们在实现下列目的所必需的范围内处理个人信息：创建与维护账户；完成登录与桌面授权；提供套餐、计费、发票与客服；调用你所选能力对应的模型；保障安全、防范欺诈与滥用；履行法律法规与监管要求；在取得同意或法律允许时改进产品体验。

官网可能在你的浏览器本地保存登录令牌（如 localStorage），以便保持登录状态。你可以随时退出登录以清除。

3. 共享、委托与跨境

我们不会出售你的个人信息。以下情形可能对外提供：

  • 模型推理：将完成任务所必需的提示词、附件摘要或生成参数发送给已接入的模型供应商；
  • 支付与发票：向支付机构或开票服务提供完成交易所需的信息；
  • 法律要求：应有权机关依法提出的要求提供；
  • 受托处理：委托云服务、邮件发送等供应商，并要求其仅按指示处理。

部分模型供应商的服务器可能位于中国境外。你使用相应模型，即理解相关内容可能发生跨境传输。我们将在能力范围内要求接收方采取合理保护措施。

4. 存储与安全

个人信息保存在实现本服务所必要的期限内：账户存续期间及注销后法律要求的最短保存期；订单与发票按财务与税务规定保存；安全日志保存合理期限后删除或匿名化。

我们采取访问控制、传输加密、密钥与密码隔离等措施。互联网环境并非绝对安全，请使用复杂密码并避免在公用设备上保存登录态。

5. 你的权利

在适用法律允许的范围内，你可以查询、更正账户资料，复制你的订单与套餐信息，改变密码，退出登录，以及申请注销账户。注销可能导致无法继续使用当期套餐，且我们可能依法保留部分交易记录。

你可以通过官网账户页管理密码与套餐，或通过本网站公示渠道提交更正、删除与注销请求。我们将在核实身份后合理期限内答复。法律另有规定的除外。

6. 未成年人

本服务主要面向成年人。不满十四周岁的儿童应在监护人同意下使用。若我们发现在未获得监护人同意的情况下收集了儿童个人信息，将尽快删除。

7. 更新与联系

我们可能修订本政策，并在官网公布。重大变更将以官网提示等方式通知。若你在变更后继续使用，即视为接受更新后的政策。

关于个人信息处理的投诉、建议或行使权利，请通过官网公示渠道联系我们。网站备案号：赣ICP备2024044295号-5。
