4. 本机工作空间

客户端会在你指定的工作空间目录内读写文件、按权限执行命令或调用已启用的连接器。请勿将系统目录、无关敏感目录或他人数据所在目录设为工作空间。

工作空间中的文件默认留在本机，不会为了「备份」而自动上传。仅当任务需要读取并发送给模型时，相关内容才会离开本机，发往相应模型供应商以完成推理。

你应自行备份重要文件。因你选择的工作空间、权限模式（含自动批准编辑或完全访问）导致的数据损失、误操作或安全事件，由你自行承担，法律另有规定的除外。
