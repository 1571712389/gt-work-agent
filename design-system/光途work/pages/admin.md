# Admin / 内部控制台 overrides

工作人员工具，与官网纸感营销页隔离。

- 画布偏冷的纸灰 `#F4F4F1`，侧栏近黑 `#171717`，不要套用官网奶油底 + 大标题 Hero
- Inter 13px 数据界面 + Fira Code 标识
- 顶栏 48px 粘性，持续显示「已登录 · 工作人员」
- 侧栏图标 16px 描边 SVG，选中用更深底，不要彩条堆砌
- KPI 自适应列、表格外包 `overflow-x: auto`，套餐表单两列网格
- 「差价」页用「份额」作为统一单位，模型配置用 Tab 切换，不要长页滚动；不要把 Token 单价卖给用户
- 登录门：左黑右表单，无注册、无回官网
- 会话键 `gt_ops_token`
- 「监测」用 Chart.js：折线看 14 日用量趋势，横向柱 / 环形看各厂商余量（份额 + 等价人民币）。空数据给说明，刷新按钮查询中禁用。
