# Shop / 官网 overrides

本页参考 Cursor 营销站的**纸感编辑风格**，不是 IDE 黑底，也不复制 Cursor 商标。

- 画布 `#F7F7F4`，正文 `#1C1917`，辅文不低于 `#57534E`
- 标题 Inter 400、负字距、大字号；不要用加粗堆权威感
- 顶栏 56px、半透明毛玻璃、中间产品/套餐、右侧「登录」文字 + 深色胶囊 CTA
- Hero 居中一句主标题 + 双 CTA；下方放工作台窗口 mock（浅色产品 UI）
- 特性用左右交替行，不要三列营销卡片堆叠
- 套餐三列，中间档细黑边作为推荐
- 主 CTA 用墨色填充，链接才用品牌蓝 `#1A7FD4`
- 禁止运营后台入口；会话键仍是 `gt_token`
- Hover 只改颜色/背景，禁止 scale
