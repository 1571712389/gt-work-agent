# Workbench overrides

Master 浅色令牌全部生效。本页：

- 输入区为白底圆角卡片 + `shadow-md`，不要贴底通栏灰条
- 空对话展示 Logo +「你好，我是光途Work」
- 任务选中用 `bg-primary/10` + 左侧 3px 主色条，不用深色块
- 问一问 / 做一做 / 想一想 使用分段控件，选中主色填充
- 对话列用容器查询随中间栏变宽：消息与输入框同一 `chat-column`，全屏时加宽，封顶约 80rem，避免 4K 一行过长
- 右侧工作空间可收起；收起后中间栏立刻吃掉宽度。切换用宽度过渡 200ms ease-out，禁止 scale
- 发送后若模型尚未吐字，对话列只显示「思考中」+ 圆点，无额外文案
- 发送消息后对话列立即滚到底部；流式输出时若用户未上翻则跟随。滚动用 `scrollTop`，尊重 `prefers-reduced-motion`，不强制 smooth
- 工作空间文件树可点选预览：图片、Markdown、CSV、代码/文本内嵌显示；其它格式提示拖到对话框或系统打开
- 工作空间文件可拖到输入卡（虚线主色覆盖层），也可点「加入对话」；选中项用 `bg-primary/10` + 左侧 3px 主色条
- 对话 Markdown：GFM 表格用表头/斑马纹/横向滚动；代码块用 JetBrains Mono + 语言标签 + 复制，行内代码与块级代码分开
- 工具结果若是 JSON/表格/Markdown，走同一套格式，不要裸 pre
- 输入卡底部显示当前模型名称，点击弹出套餐内模型列表（按厂商分组），选中项对勾；无 hover scale
- 支持拖入 / 粘贴 / 选择文件与图片：拖入时虚线主色覆盖层；图片缩略图 + 文件芯片可移除；图标用 Lucide
- 识图走多模态模型（DeepSeek Flash / V4 Pro 等）；当前模型不支持时自动切到可用识图模型并文字提示
